# 침해대응의 달인 · Incident Master

클라우드 기업이 실제 침해사고를 당한 상황을 읽고, 참가자가 대응 행동의 순서를 실물 꼬치로 정하는 **BEAVER DAM 커뮤니티 부스 체험형 웹앱**입니다.

참가자는 먼저 사고 제목과 상황만 10초 동안 읽습니다. 커튼 전환 뒤 재료별 행동 카드가 무작위 순서로 공개되며, 50초 동안 행동을 판단해 꼬치를 조립합니다. 시간이 끝나면 `끝!`과 `정답 보기`가 나타나고, 버튼을 누른 뒤에만 해당 회차의 정답 꼬치와 해설을 확인할 수 있습니다.

## 바로 실행하기

1. 이 레포의 **Code → Download ZIP**을 눌러 내려받거나 아래 명령으로 복제합니다.
2. 압축을 푼 폴더의 **`dist/index.html`**을 브라우저에서 엽니다.
3. ‘게임 방법’을 확인하고 **‘무작위 사고 시작’**을 누릅니다.

```sh
git clone https://github.com/Beaver-Dam-Community/Incident-master.git
cd Incident-master
```

로그인·회원가입·서버 설치가 필요 없습니다. 폰트와 그림이 포함돼 있어 오프라인에서도 실행할 수 있습니다. 옮길 때는 **dist 폴더 전체**를 유지해 주세요.

로컬 웹서버로 실행하려면 Python 3가 있는 환경에서 다음 명령을 사용합니다.

```sh
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

브라우저에서 <http://127.0.0.1:4173/>을 엽니다. 웹으로 배포할 때도 `dist/` 전체를 정적 웹서버에 올리면 됩니다.

## 게임 진행

1. **사고 브리핑 — 10초:** 제목과 상황만 표시합니다. 대응 행동과 정답 순서는 보이지 않습니다.
2. **커튼 전환:** 짧은 커튼 효과로 상황 화면에서 대응 화면으로 넘어갑니다. 동작 줄이기를 설정한 기기에서는 효과가 줄어듭니다.
3. **행동 카드 — 50초:** 행동 카드를 무작위 순서로 보여줍니다. 카드 순서는 정답 순서가 아닙니다. 참가자는 실제 꼬치에 행동을 순서대로 끼웁니다.
4. **시간 종료:** 큰 `끝!` 표시와 `정답 보기` 버튼이 나타납니다. 버튼을 누르기 전까지 정답 꼬치는 공개하지 않습니다.
5. **정답 확인:** 이번 회차에 배정된 재료와 행동이 들어간 정답 꼬치 그림, 순서별 이유, 그리고 **클라우드라서 일반 침해사고 대응과 다른 점**을 보여줍니다.
6. **다음 팀:** 다음 팀을 준비하면 새 사고를 무작위로 뽑습니다.

- 시나리오는 한 묶음에서 한 번씩 무작위로 뽑고, 모두 나온 뒤 다시 섞습니다. 직전 시나리오는 바로 반복하지 않습니다.
- 각 회차에 행동과 재료의 연결을 새로 섞고, 행동 카드 제시 순서도 별도로 섞습니다. 같은 사고가 다시 나와도 두 배열은 직전 배열과 달라집니다.
- 새로고침해도 현재 회차, 타이머와 무작위 배정이 복원됩니다. 브라우저 저장이 제한된 환경에서는 복원이 제한될 수 있습니다.
- 재료 순서 입력이나 자동 채점은 없습니다. 참가자가 실제 꼬치를 만들고 진행자와 함께 정답을 확인합니다.
- 치즈와 베이컨은 납작하게 지그재그로 접어 **각각 독립된 한 칸**에 끼웁니다. 다른 재료를 감싸지 않습니다.
- 진행자는 정답 화면 아래의 시나리오 A~E 코드로 답안과 연결할 수 있습니다.
- 진행 중에는 게임 화면 오른쪽 위, 타이머 옆에 시간 종료 버튼이 있습니다. 상황 단계에서는 **바로 행동 보기**로 행동 카드를 바로 공개하고, 행동 단계에서는 **지금 끝내기**로 남은 시간과 상관없이 `끝!` 화면으로 넘어갑니다. 정답은 이때도 `정답 보기`를 눌러야 공개됩니다.
- ‘게임 방법’의 각 단계에는 실제 게임 화면과 같은 모양의 예시 화면이 함께 나옵니다. 예시는 실제 시나리오가 아닌 가상의 계정 탈취 사고라서 정답이 미리 노출되지 않습니다.

## 시나리오

이 앱에는 새로 구성한 클라우드 침해사고 5종이 들어 있습니다(AWS 3종, Google Cloud 1종, Azure 1종). 기존의 작은 단일 설정 문제 대신, 공격 경로·영향 조사·클라우드 권한·복구와 재발 방지까지 이어지는 교육용 가상 사고입니다.

| 코드 | 사고 |
| --- | --- |
| A | GitHub Actions 자동 배포 경로가 침해돼 AWS 운영 서비스에 승인되지 않은 프로그램이 배포되고 고객 정보 전송 흔적이 발견됨 |
| B | AWS 쿠버네티스 서비스(EKS)에서 채굴 악성코드가 실행되고 서버의 클라우드 접근 권한이 악용됨 |
| C | 공개된 AWS 웹 서버가 해킹돼 서버에 연결된 권한으로 고객 정보 저장소에 접근함 |
| D | Google Cloud 서비스 계정 키가 유출돼 BigQuery 고객 데이터가 회사 밖 프로젝트로 내보내짐 |
| E | Azure 관리자 계정이 탈취돼 스스로 권한을 올리고 관리 화면의 명령 실행 기능으로 서버 30대에 프로그램을 설치함 |

다섯 상황은 실제 특정 기업의 사건을 재현하거나 발생 사실을 주장하지 않습니다. 행동 순서는 각 상황에 맞춘 대표 흐름입니다. 격리와 자료 보존처럼 실제 사고에서 함께 시작할 수 있는 조치는 대체 순서도 인정합니다. 조사에서 아직 확인되지 않은 계정·키·숨은 접속 수단을 먼저 가정하지 않고, 조사에서 발견한 뒤 차단·제거하도록 구성했습니다.

## 파일 구성과 수정

| 경로 | 용도 |
| --- | --- |
| `dist/` | 브라우저에서 바로 실행하고 배포하는 웹앱 전체 |
| `dist/app.js` | 화면, 게임 방법, 게임 단계와 정답 공개 |
| `dist/game-engine.js` | 시나리오 추첨, 회차별 셔플, 타이머와 저장·복원 |
| `dist/participant.css` | 상황실 화면, 커튼, 행동 카드, 반응형 디자인 |
| `dist/theme.css` | 모든 화면에 공통으로 적용하는 밝은·어두운 테마 색 |
| `dist/assets/` | 로고, 재료 그림, 포함된 폰트와 폰트 라이선스 |
| `compiled-catalog.json` | 현재 다섯 시나리오의 제목·상황·행동·정답·해설 기준 |
| `compiled-source-reference.json` | 기존 자료의 과거 참조본. 현재 게임 시나리오의 출처가 아님 |
| `scenario-codes.json` | 다섯 시나리오 ID와 A~E 코드 연결 |
| `build_web_data.py` | 기준 데이터를 검증하고 `dist/scenarios.js`, 폰트를 내장한 `dist/fonts.css` 생성 |
| `tests/` | 시나리오, 타이머, 무작위 배정, 저장·복원 검증 |

시나리오를 바꿀 때는 `compiled-catalog.json`을 수정하고 다음 명령으로 검증 및 브라우저 데이터를 생성합니다.

```sh
python build_web_data.py
```

검증은 Node.js 22 이상에서 실행할 수 있습니다. 별도 패키지 설치는 필요 없습니다.

```sh
npm test
```

테스트는 다섯 시나리오의 구조와 답안, 10초·50초 단계 전환, 커튼 구간, 정답 공개 조건, 무작위 재료 배정과 카드 순서, 새로고침 복원을 확인합니다.

## 디자인과 자료

- 브랜드명은 **BEAVER DAM**, 게임명은 **침해대응의 달인**입니다.
- 홈부터 상황·행동·정답 화면까지 모든 화면이 같은 테마를 씁니다. 헤더의 해/달 버튼으로 **밝은 테마와 어두운 테마**를 바꿀 수 있습니다.
- 처음에는 기기의 밝기 설정을 따르고, 한 번 고른 테마는 브라우저에 저장돼 다음에 열 때도 유지됩니다.
- 큰 제목·재료 이름에는 Jua, 설명·재료 행동·해설에는 Pretendard를 사용합니다.
- 색만으로 상태를 전달하지 않고, 작은 화면과 동작 줄이기 설정도 지원합니다.
- 로고는 BEAVER DAM 커뮤니티에서 제공한 자료입니다.
- [Jua](https://fonts.google.com/specimen/Jua)와 [Pretendard](https://github.com/orioncactus/pretendard)의 라이선스는 각각 `dist/assets/Jua-OFL.txt`, `dist/assets/Pretendard-OFL.txt`에 포함했습니다.
